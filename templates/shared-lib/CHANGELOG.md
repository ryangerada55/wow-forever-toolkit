# LibTx-1.0 changelog

Every release bumps MINOR in `LibTx-1.0.lua` and gets a tag `vX.Y.Z`. Addons pin the tag in
their `.pkgmeta`, so a change reaches players only when each addon updates its pin and releases.

## v1.0.0 (MINOR 1)

- First version: `GetFlavor`, `IsFlavorSupported`, `IsSecret`, `RegisterPrefix`.
